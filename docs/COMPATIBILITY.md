# 兼容性与已知限制

[返回项目首页](../README.md)

当前为开发验证版。本页区分产品面向的场景、已实现的接入流程与尚待完成的真实环境验证。

## 输入法

产品用于带候选词、需要转换或确认上屏的输入法场景。程序依据网页收到的输入法组词事件判断状态，无需读取候选词窗口及其中的文字。不同输入法的兼容性需要分别验证。

| 输入法范围 | 当前状态 |
| --- | --- |
| macOS 系统自带拼音 | 首轮验证对象；真实系统输入法与硬件按键端到端验收尚未完成 |
| 其他中文输入法，包括其他拼音、五笔等 | 面向的使用场景，需逐一实测 |
| 日文、韩文等带候选词或转换过程的输入法 | 存在类似需求，尚未验证兼容性 |

具体确认哪些文字，沿用输入法本身的回车规则。空格、数字键与方向键等选词操作保持原有行为；带 Shift、Command、Control 或 Option 的回车快捷键保持原有行为。

## 浏览器

| 浏览器 | 当前状态 |
| --- | --- |
| Safari、Chrome | 主要适配目标，已接入连接与保护流程；真实网页端到端验证仍待完成 |
| Microsoft Edge、Arc、Brave、Vivaldi、Opera | 已接入连接、暂停与自动断连流程；尚未在本机完成真实连接、输入与窗口关闭验收 |

连接与窗口检测脚本已经离线编译验证。实际兼容性仍需结合具体浏览器版本、输入法和网站验证；未安装的浏览器无法连接。

## 系统与分发

最低部署版本设为 macOS 14.0。目前在 Apple Silicon、macOS 27.0 环境完成构建，旧版系统与 Intel Mac 尚未实测。当前为本机 ad-hoc 签名构建，尚未提供公证安装包。

## 网页范围

- 保护已连接浏览器的前台标签页顶层网页，不覆盖所有 macOS 应用。
- 跨域 iframe、浏览器内部页面和闭合 Shadow DOM 尚未覆盖。
- 新开、刷新或切换网页后，可能有约 1 秒的保护安装间隙。
- 部分富文本编辑器和自定义输入组件仍需逐站验证。
- 已先于保护脚本注册的 `window` 捕获阶段处理器，可能先收到事件。
- 暂停或退出后，后台页的保护租约最多 4 秒后失效；正在确认的同一次长按按键仍保持成对处理。

## 人工验证

先在应用内「输入测试」页操作，再在实际网站验证：

1. 使用真实键盘和日常使用的输入法，输入一段仍在组词、尚未确认的文字。
2. 按一次回车，检查文字是否按输入法原有规则上屏，提交次数是否保持不变。
3. 检查原文是否完整，是否出现重复、漏字或额外换行。
4. 松开后再按一次回车，检查是否正常提交，无需人为等待。
5. 验证正常选词、直接英文输入、修饰键快捷键、长按回车和焦点切换。
6. 到常用网站重复操作，检查是否出现误搜索、误发送或意外跳转。

自动输入或合成网页事件不能替代真实输入法验收。建议在可安全测试的输入框中验证。

反馈问题时，请记录 macOS 版本、输入法及版本、浏览器及版本、网站与具体复现步骤。
